# 国际化（i18n）

Kerno 组件里所有显示或读给读屏软件的文案（按钮标签、占位文字、校验提示、分页摘要、日期名称……）都来自 `@kerno/core` 的消息表，并按元素所在的语言渲染。

## 语言从哪里来

组件取离自己最近的 `lang` 属性（会穿过 Shadow DOM 往上找），都没有时使用英文：

```html
<html lang="zh-CN">
  …
  <section lang="en"><k-dialog label="Settings"></k-dialog></section>
</html>
```

运行时修改任意元素的 `lang`，其中的组件会自动重新渲染。

## 注册语言

内置英文。其他语言按需引入，没有副作用，不引入就不会打进包里：

```ts
import { registerLocale } from '@kerno/core';
import { zhCN } from '@kerno/core/locales/zh-CN';

registerLocale(zhCN);
```

匹配规则：`zh-Hant-TW` 依次尝试 `zh-hant-tw` → `zh-hant` → `zh`，再找任意 `zh-*`，最后回退到英文；大小写不敏感。缺失的 key 也会回退到英文。

## 自定义文案

同一个 `code` 可以多次注册，后注册的覆盖前面的，英文也可以覆盖：

```ts
registerLocale({ code: 'en', messages: { close: 'Dismiss' } });
registerLocale({ code: 'fr', messages: { close: 'Fermer', remove: (item) => `Retirer ${item}` } });
```

带参数的消息是函数，由各语言自己决定语序和复数。完整的 key 列表见 `packages/core/src/locales/en.ts`；`KernoMessages` 类型可以用来校验完整翻译（参考 `zh-CN.ts`）。

组件上的文本属性（`placeholder`、`label`、`empty-text`、`show-label` 等）显式设置时优先于消息表；默认值改为空字符串，表示“使用本地化文案”。

## 日期与数字

日期名称（月份、星期、无障碍日期标签）和数字（数据表格行数、数字输入框范围提示）使用 `Intl.DateTimeFormat` / `Intl.NumberFormat`，按同样的语言格式化。

## 在自己的组件里使用

```ts
import { KernoElement, LocalizeController, setLabels } from '@kerno/core';

class MyWidget extends KernoElement {
  readonly #localize = new LocalizeController(this);

  protected override update(): void {
    setLabels(this.renderRoot, [['.close-btn', this.#localize.term('close')]]);
  }
}
```

表单控件（继承 `FormAssociatedElement`）直接使用 `this.localize`。文案要在 `update()` 里设置，不要写进静态模板，这样语言变化时才会刷新。

## 已知限制

- 浏览器原生的校验提示（`k-input` 等内部 `<input>` 的 `validationMessage`）使用浏览器界面语言，不受 `lang` 影响。
- 只观察 light DOM 里的 `lang` 变化；Shadow DOM 内部的 `lang` 变化会在组件下次更新时生效。
